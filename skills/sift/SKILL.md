以使用者提供的關鍵字，對指定範圍的文件逐階段收斂，每階段以整份檔案為比對單位。

# 別名
- 別名是同一概念在該領域實際通用的稱呼，包含同義詞與縮寫。每個說法列出繁體中文、簡體中文、英文寫法，各採該語言文化的慣用語，不直接翻譯，不收會造成誤會的詞。
- 產生別名前不讀取搜索範圍內的檔案與檔名。
- 同一階段的全部別名合併為一份清單，彼此為 OR 關係，於搜索前寫入 `<D>/N.alias`，每行一詞。

# 搜索
- 第 1 階段開始時以 `mktemp -d /tmp/sift.XXXXXX` 建立工作目錄 `<D>`，後續階段沿用。
- 第 1 階段的搜索詞是使用者提供的關鍵字與其別名，第 N 階段的搜索詞是使用者選定項的成員與其別名。
- 一律用 `rg`，固定字串、不分大小寫、只輸出檔名，不使用 `--hidden`。
- 第 1 階段搜索使用者指定的範圍：`rg -F -i -l -f <D>/1.alias <範圍> > <D>/1.files`
- 第 N 階段搜索第 N−1 階段通過的檔案：`xargs -r -d '\n' rg -F -i -l -f <D>/N.alias < <D>/<N-1>.files > <D>/N.files`

# 回報
- 通過檔數與搜索檔數。
- 每個別名的命中檔數，標出命中 0 者供使用者增刪。
- 通過檔案中命中詞前後 20 字的原文片段：`xargs -r -d '\n' rg -o -i -e '.{0,20}(?:<正規式跳脫後以 | 連接的別名>).{0,20}' < <D>/N.files`
- 依片段歸納下一階段候選項，每項是一種用法，用法指原文中的比較對象、觸發方式與作用。只依用法分項，指標、計算方式、詞面或參數不同而用法相同者併為一項，同一詞的不同用法各自成項，不依預設立場或常見程度取捨。項的成員取自原文的內容概念用詞，不含文件格式與句型用詞。每項附成員、去重後的命中檔數與片段。
- 使用者給出判準時，讀完每項成員在通過檔案中的完整命中行，依判準分類計數，附一句最符合判準的內容摘要，不轉貼原句。判準只取自使用者本次說明的目的，未給時先詢問。
