以使用者提供的關鍵字，對指定範圍的文件逐階段收斂，每階段以整份檔案為比對單位。

# 別名
- 別名是同一概念在不同作者筆下的各種說法，包含同語言的同義詞與縮寫，不擴及其他概念。只收該領域實際通用的說法，不自行拼組字面合理但少有人用的詞。每個說法列出繁體中文、簡體中文、英文寫法，簡體由繁體字形轉換。
- 產生別名前不讀取搜索範圍內的檔案與檔名，也不以先前階段結果的用詞為依據。
- 同一次提供的多個關鍵字屬於同一階段，該階段全部別名合併為一份清單，彼此為 OR 關係，於搜索前寫入 `/tmp/sift/<階段>.alias`，每行一詞。

# 搜索
- 一律用 `rg`，固定字串、不分大小寫、只輸出檔名。
- 預設略過隱藏檔與 .gitignore 排除的檔案，使用者指定時才加 `--hidden --no-ignore`。
- 第 1 階段搜索使用者指定的範圍：`rg -F -i -l -f /tmp/sift/1.alias <範圍> > /tmp/sift/1.files`
- 第 N 階段重新搜索第 N−1 階段通過的整份檔案，不要求與前階段關鍵字同行：`xargs -r -d '\n' rg -F -i -l -f /tmp/sift/N.alias < /tmp/sift/<N-1>.files > /tmp/sift/N.files`

# 回報
- 通過檔數與搜索檔數。
- 每個別名的命中檔數，標出命中 0 者供使用者增刪。
- 通過檔案中命中詞前後 20 字的原文片段：`xargs -r -d '\n' rg -o -i -e '.{0,20}(?:<正規式跳脫後以 | 連接的別名>).{0,20}' < /tmp/sift/N.files`
- 依片段歸納主題，每主題附去重後的檔數與片段，不依預設立場取捨。
- 每次回報都附下一階段候選關鍵字，從本階段結果的原文取詞，附命中數。使用者選定後，其別名依別名段產生。
- 判準只取自使用者本次說明的目的。使用者給出判準時，讀完每個候選詞在通過檔案中的完整命中行，依判準分類計數，附一句最符合判準的內容摘要，不轉貼原句。未給判準時先詢問，不自訂判準。
- 下一階段關鍵字由使用者決定。
