  ### 前提檢查與當前結論 (Premise Check & Conclusion)

  • 前提 1：AI 寫出的測試多為無關緊要的「垃圾測試」，只要沾到邊（覆蓋率上升）就拿滿分？
      • 成立。傳統程式碼覆蓋率（Code Coverage）僅偵測代碼是否被執行（Execution），並不評估斷言（Assertion）的有效性。AI Agent
      極易生成只調用函數卻無實質斷言、或僅驗證微不足道邏輯的低價值測試，來快速湊足覆蓋率分數。
  • 前提 2：應對測試進行邊際效益分級與取捨，使 Token 消耗有實質價值？
      • 成立。測試程式碼本身是維護成本，若容許低價值測試進入代碼庫，後續的維護與 CI 執行將造成嚴重的「Token 與算力浪費」。
  • 當前結論：2026 年中旬的業界共識已從「盲目追求覆蓋率」轉向**「測試有效性篩選（Test Efficacy Filtering）」**。主要透過**突變測試（Mutation
  Testing）**與**雙 Agent 語意審查**來實施測試剪枝（Pruning），剔除無效的垃圾測試。

  ### 現實可行性分析（對象、動作、原因、解法）

  #### 1. 突變測試過濾器 (Mutation Testing Quality Gate)

  • 對象：Agent 新生成的測試案例。
  • 動作：在 CI 流程或本地驗證中，自動在原始代碼引入人工 bug（Mutants，例如將  >  改為  < ），並執行 Agent 寫的測試。若測試未因此失敗（Mutant
  survived），則判定為無效測試並自動刪除。
  • 原因：突變分數（Mutation Score）能精準衡量測試的「Bug 檢出能力」。不具備檢出能力的測試，其邊際效益為零，不應留存。
  • 解法：在  deve  規約中整合輕量突變測試工具（如 Python 的  mutmut 、JS/TS 的  Stryker ），對 Agent
  產出的測試強制實施「突變存活篩選」，存活率過高的測試直接捨棄。

  #### 2. 雙 Agent 審查機制 (Dual-Agent Review for Triage)

  • 對象：測試套件的斷言品質與語意重疊度。
  • 動作：引入第二個專門作為「審查者（Reviewer）」的輕量 LLM Agent，評估測試案例的斷言強度，並與現有測試進行語意相似度比對。
  • 原因：單一 Agent 在生成代碼時容易因目標單一（Pass verification）而編寫敷衍的 assertion。透過 Generator-Critic（生成-審查）雙重約束，能以低
  Token 成本在本地過濾掉 Trivial（顯而易見）的測試。
  • 解法：在提示詞鏈中加入 Review 步驟。要求審查 Agent
  提問：「若刪除此測試，是否有任何核心邏輯或邊界條件會失去保護？」若答案為否，則判定為低邊際效益，予以拒絕。

  #### 3. 測試邊際效益分級原則 (Utility-Based Test Triage)

  • 對象：待寫入的測試案例。
  • 動作：依邊際效益將測試分級並採取不同策略：
      • 高邊際效益（必須寫入）：核心業務邏輯、複雜狀態轉移、邊界條件（Edge Cases）、以及高風險的防禦性 assertion。
      • 中邊際效益（酌量寫入）：標準 Happy Path、與其他測試路徑高度重疊但參數不同的輸入組合。
      • 低邊際效益（直接拒絕）：單純的 getter/setter 測試、缺乏有意義 assertion 的結構性調用。
  • 原因：測試代碼即技術債。減少低邊際效益的測試，能顯著提升 CI 執行速度，並降低代碼重構時修改測試的負擔。
  • 解法：修訂  deve  的「開發規約」，將**「優先覆蓋高風險與核心邊界」**具體化，禁止 Agent 為追求 100% 覆蓋率而自動產生 boilerplate/trivial
  測試。

  ### 證據與搜尋評估 (Evidence & Search Evaluation)

  • 強烈證據與來源限制：各大技術團隊實踐指出，AI 生成測試若不經篩選，會增加 15-20% 的維護負擔。突變測試（Mutation Testing）在 2026
  年已被證明是檢驗 AI 測試品質最可靠的自動化防線。
  • 適用範圍：此過濾邏輯適用於有明確斷言對象的單元測試與整合測試；不適用於單純驗證「不崩潰即可」的冒煙測試（Smoke Tests）。
  • 終止進一步搜尋的原因：測試剪枝與有效性驗證的技術手段（Stryker/mutmut、雙 Agent
  審查、邊際效益分級）在業界已相當成熟，進一步搜尋僅會重疊已知模式，無助於改變當前決策。
