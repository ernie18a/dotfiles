# painpoint


## 步驟

1. 讀取目標檔案，辨識文件中提到幾個獨立問題
2. 每個問題建一個 `## 問題 N：<標題>` 分組
3. 該問題的解法/工具/技術，整理成 `-` 清單
4. 原始檔案以整理後的版本原地覆寫（或依使用者指定路徑輸出）

## 輸出格式

```
# <主題>

## 問題 N：<標題>

- item
- item

---

## 問題 N+1：<標題>

- item
```

## 原則

- 分組數量由問題數量決定，不多不少
- 同一問題有多方案時，用粗體標示方案名稱再列清單
- 不加解釋、不加建議語氣
