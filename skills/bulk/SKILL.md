# 目的
- `/g/data/tv26101718708/.volume/.o/*.md` 是策略判斷邏輯摘要。
- 產生讓新 session 的 AI 能取用全部資料的產物，並在其上去重收斂。

# 執行
- `/bulk 0` 建表，產物寫入 `.o/.table/`。
- `/bulk 1`、`/bulk 2`、`/bulk 3` 各用一種整合方式，讀取 `.o/*.md` 與 `.o/.table/`，產物分別寫入 `.o/.sort/`、`.o/.pair/`、`.o/.run/`，不修改 `.o/.table/`。
- 逐份或逐批工作交給獨立 context 的 subagent，subagent 把結果寫入檔案，只回傳檔案路徑。
- 整合結束時由程式確認全部規則行都在 `groups.tsv` 中，不通過就修正到通過。

# 建表
- 以規則行為單位逐份抽取，每列含原檔名、行號、規則類型、核心機制欄位、原句。
- 先抽樣定義扁平的 canonical 欄位，值域用封閉清單限制，模型只映射到既有欄位。
- 輸出後用程式正規化格式，統一 key，缺欄位補 null。
- 抽取後詢問遺漏並補抽，設定輪數上限。
- 由程式確認全部規則行都在表中，每列原句都存在於原檔，不通過就修正到通過。

# 去重原則
- 大同小異指核心判斷的數學結構相同。參數數值、同類指標替換、附加的濾網都屬於小異。判斷方向或觸發結構不同就是不同邏輯。
- 濾網與出場整理成該群的可選濾網與出場變體。出場或部位管理本身是核心時，納入分群依據。
- 一份檔案含多個獨立邏輯時拆開，分別歸群。
- 每群以構成方式描述共同的核心邏輯，列出成員與各自的小異。獨立邏輯同樣成群。

# 第 1 種：分類體系歸納
- 抽幾十份樣本，由 LLM 多步迭代產生分類體系，再逐份歸類全部檔案。
- 依計算、進場、出場、濾網等機制面向分群建階層。

# 第 2 種：候選對判定與全域一致性
- 以表的機制欄位縮小候選配對，或全兩兩比對。
- LLM 對每對判定是否同一機制並給信心分數。每對對調順序各判一次，不一致者升級複審。每批 20–30 對。
- 以信心為邊權重，用 correlation clustering 移除造成不一致的弱邊。

# 第 3 種：執行行為比對
- 把每份邏輯轉成可執行程式，在同一份 K 線資料上執行，比對做多、做空、出場訊號的重疊程度。訊號幾乎相同即大同小異。

# 產物
- `.table/rules.tsv`：建表結果。
- 各整合資料夾的 `groups.tsv`：每列為原檔名、行號、群組代號、判定依據。
- 各整合資料夾的群組說明：從群組代號可查到核心邏輯、可選濾網、出場變體與成員小異。
- `USAGE.md`：後續對話規則全文。

# 後續對話規則
- 問題牽涉全體時，以程式查詢產物作答。
- 回答附覆蓋數，包含納入的檔案數與規則行數。
- 需要語意判斷時，把查出的全部列分批逐一處理，每批 100 列以內。
