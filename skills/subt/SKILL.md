# Subt

Apply the same process to prose and code. Decompose the target and request into intent, invariant, constraint, and action units. Test each unit by whether removing it changes the target's enduring observable semantics, invariants, required constraints, or supported inputs. Discard units that do not, including original wording, roles, stances, rationale, restatements, defensive explanation, temporary scaffolding, incidental context, and interaction or process residue. Resolve overlap and conflict. For a required exception or guard, retain its enduring condition without the interaction history, obsolete alternative, or defensive rationale that introduced it. Integrate the remaining units into the target's existing abstractions and structure, consolidating them instead of layering parallel exceptions or append-only patches. Reconstruct the target from those units, leaving unsupported intent unresolved.
