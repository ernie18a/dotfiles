以使用者提供的關鍵字，對指定範圍的文件逐階段收斂，各階段關鍵字疊加於同一行。

# 別名
- 別名是同一概念在不同作者筆下的各種說法，包含同語言的同義詞與縮寫。只收該領域實際通用的說法。每個說法列出繁體中文、簡體中文、英文寫法，簡體由繁體字形轉換。
- 產生別名前不讀取搜索範圍內的檔案與檔名，也不以先前階段結果的用詞為依據。
- 同一次提供的多個關鍵字屬於同一階段，該階段全部別名合併為一份清單，彼此為 OR 關係，於搜索前寫入 `/tmp/sift2/<階段>.alias`，每行一詞。

# 搜索
- 一律用 `rg`，不分大小寫。
- 隱藏檔案與隱藏資料夾須經使用者准許才可存取，准許時加 `--hidden`。
- 第 1 階段輸出 `檔名:行號:內文`：`rg -F -i -H -n --no-heading -f /tmp/sift2/1.alias <範圍> > /tmp/sift2/1.lines`
- 第 N 階段只比對前一階段各行的內文：`rg -i -e '^[^:]*:[0-9]+:.*(?:<正規式跳脫後以 | 連接的 N 階段別名>)' /tmp/sift2/<N-1>.lines > /tmp/sift2/N.lines`

# 回報
- 通過行數，以及檔名去重後的檔數。
- 每個別名的命中行數與檔數，標出命中 0 者供使用者增刪。
- 命中詞前後 20 字的原文片段，只取內文：`cut -d: -f3- /tmp/sift2/N.lines | rg -o -i -e '.{0,20}(?:<正規式跳脫後以 | 連接的別名>).{0,20}'`
- 依片段歸納下一階段候選項，每項是一種用法，用法指原文中的比較對象、觸發方式與作用。只依用法分項，指標、計算方式、詞面或參數不同而用法相同者併為一項，同一詞的不同用法各自成項，不依預設立場或常見程度取捨。項的成員取自原文的內容概念用詞，不含文件格式與句型用詞。每項附成員、去重後的命中行數、檔數與片段。
- 使用者選定的項，其成員連同各自依別名段產生的別名，作為下一階段的搜索詞。
- 使用者給出判準時，讀完每項成員在本階段通過行中的完整命中行，依判準分類計數，附一句最符合判準的內容摘要，不轉貼原句。判準只取自使用者本次說明的目的，未給時先詢問。
