以使用者提供的關鍵字，對指定範圍的文件逐階段收斂，每階段只在前一階段通過的行中搜索，各階段關鍵字疊加於同一行。

# 別名
- 使用者每給一個關鍵字，產生繁體中文、簡體中文、英文別名，同一階段的全部別名為 OR 關係。
- 繁簡只做字形轉換，英文取該領域常用詞與縮寫，不加入使用者關鍵字以外的概念。
- 別名清單寫入 `/tmp/sift2/<階段>.alias`，每行一詞。

# 搜索
- 一律用 `rg`，不分大小寫。
- 預設略過隱藏檔與 .gitignore 排除的檔案，使用者指定時才加 `--hidden --no-ignore`。
- 第 1 階段輸出 `檔名:行號:內文`：`rg -F -i -H -n --no-heading -f /tmp/sift2/1.alias <範圍> > /tmp/sift2/1.lines`
- 第 N 階段只比對前一階段各行的內文，不比對檔名：`rg -i -e '^[^:]*:[0-9]+:.*(?:<正規式跳脫後以 | 連接的 N 階段別名>)' /tmp/sift2/<N-1>.lines > /tmp/sift2/N.lines`

# 回報
- 通過行數，以及檔名去重後的檔數。
- 每個別名的命中行數與檔數，標出命中 0 者供使用者增刪。
- 命中詞前後 20 字的原文片段，只取內文：`cut -d: -f3- /tmp/sift2/N.lines | rg -o -i -e '.{0,20}(?:<正規式跳脫後以 | 連接的別名>).{0,20}'`
- 依片段歸納主題，每主題附命中檔數與片段，不依預設立場取捨。
- 下一階段關鍵字由使用者提供，使用者要求時才提出候選。
