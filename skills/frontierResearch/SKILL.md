# Frontier Research

## Purpose

Use this workflow when a normal answer is likely to repeat common explanations, obvious entities, or generic best practices.

The goal is to:
- identify the generic-answer baseline
- search beyond that baseline
- prioritize high-signal evidence
- group independent findings
- preserve contradictions and uncertainty
- synthesize what is better than the generic answer

## Baseline Boundary

Define the baseline only when enough context exists. The baseline is the visible generic answer pattern before deeper research:

- common explanations
- standard frameworks
- obvious entities
- repeated examples
- generic best practices

Use the baseline as a moving boundary, not as the research target. Update it when new structure appears.

## Orientation

Adapt to the question shape:

- If the domain is unclear, first map concepts, entities, methods, relations, and uncertainties.
- If the generic answer is already obvious, state it briefly and move beyond it.
- If new terms, mechanisms, entities, or contradictions appear, redirect toward the higher-signal path.

Do not infer hidden behavior or unavailable internal facts. Mark them as unknown.

## Search Waves

Use staged search:

1. Start broad enough to expose multiple independent paths.
2. Identify which paths are baseline repetition, weak aggregation, or high-signal frontier material.
3. Deepen the high-signal paths.
4. Stop paths that only repeat the baseline or low-information claims.
5. Switch to synthesis when new searches mostly repeat known clusters.

Prefer depth in strong paths over collecting many shallow pages.

## Signal Quality

Prioritize:

- primary sources
- direct evidence
- reproducible details
- domain-specific sources
- expertise proximity
- verifiable mechanisms
- independent convergence
- unexpected but explainable relations

Reduce confidence in:

- shallow summaries
- circular citations
- copied aggregation
- engagement-optimized content
- generic AI-style explanations
- novelty without evidence

## Finding Clusters

Count independent finding clusters, not pages.

A useful cluster should explain something beyond the baseline and have at least one clear evidence path. Stronger clusters have independent support, mechanism-level detail, or direct source proximity.

When clusters conflict, preserve the conflict and compare assumptions, dates, definitions, incentives, and source quality.

## Output

Return only the parts that fit the task:

- premise check
- baseline answer
- findings beyond baseline
- finding clusters
- recurring signals
- major entities
- relationship structure
- contradiction zones
- unresolved uncertainty
- unexplored branches
- confidence estimate

Keep the answer focused on what changed after crossing the baseline.
