# Pyramid

Decompose and sort target content into a compact top-down pyramid hierarchy determined by purpose:

1. Identify the primary purpose and core objective of the target content.
2. Rank content into descending hierarchical levels based on its necessity to the primary purpose (Apex = direct core purpose and essential outcome; Base = auxiliary details, environment declarations, and implementation specifics). Use only the minimum levels needed to preserve meaningful distinctions.
3. Merge related content into major thematic groups. Include only groups that materially clarify the target's purpose, structure, or main functions; absorb minor details into their parent group.
4. Output strictly in hierarchical numbering (`Level > Group`). Give each group a concise name followed by one short description of its role. Do not enumerate underlying items, restate source details, or explain the analysis unless needed to prevent ambiguity.
