# 避免下列錯誤：

- 使用決策當下尚未可知或尚未確認的資料，例如 `Close[t+1]` 或尚未公布的完整統計值。
- 把事後才定格的重繪指標或未收盤 K 線當成固定資料。
- 讓低週期策略讀取尚未收盤的高週期資料。
- 混用盤中訊號、收盤後條件與不可能取得的成交時點。
- 在切分訓練集與測試集前，使用全資料做正規化、特徵選擇或缺值處理。
- 用隨機或重疊的時間序列切分方式造成資料洩漏。
- 忽略存活者偏差、下市標的、資料修訂、發布時間、時區或公司行動。
- 在同一份歷史資料反覆搜尋參數、指標、特徵、市場或時間區間。
- 測試大量候選後只採用最佳者，卻忽略嘗試次數與選擇偏差。
- 看過 out-of-sample 或測試集結果後繼續修改策略。
- 模型自由度相對有效樣本量過高。
- 只用單一市場狀態、單一標的或過短期間驗證策略。
- 只接受最佳參數點，而不檢查鄰近參數與不同樣本的穩定性。
- 以 `Low <= LimitPrice` 認定限價單必然立即全額成交。
- 用 K 線收盤資料產生訊號，卻假設能以同一收盤價成交。
- 忽略延遲、跳空、滑價、費用、排隊順位、部分成交、可成交量與市場衝擊。
- 使用超出實際流動性、槓桿、保證金、借券或資金費率限制的部位。
- 假設回測與實盤具有相同的同步訂單狀態；忽略重複送單、拒單、撤單與成交回報延遲。
- 假設任意價格與數量都可下單；忽略 tick size、lot size 與最小名目金額。
- 只看報酬而忽略最大回撤、尾端風險、連續虧損、爆倉與破產條件。
