# 避免過度擬合與不實回測

- 只使用決策當下已知且已確認的資料；不得使用 `Close[t+1]`、尚未公布的完整統計值、事後定格的重繪指標、未收盤 K 線或未收盤的高週期資料。對齊盤中訊號、收盤後條件與實際可成交時點。
- 先按時間切分訓練集與測試集，再各自進行正規化、特徵選擇及缺值處理；時間序列切分不得隨機或重疊。納入存活者偏差、下市標的、資料修訂、發布時間、時區與公司行動。
- 將參數、指標、特徵、市場及區間的所有嘗試納入選擇偏差控制；不得看過 out-of-sample 或測試集後繼續修改策略。限制模型自由度相對於有效樣本量。
- 用多種市場狀態、標的及足夠長的期間驗證，並檢查鄰近參數與不同樣本的穩定性，不只接受最佳參數點。
- 依可實現的訂單生命週期與市場限制模擬成交：`Low <= LimitPrice` 不代表限價單立即全額成交；收盤訊號不能假設以同一收盤價成交。納入延遲、跳空、滑價、費用、排隊順位、部分成交、可成交量、市場衝擊、重複送單、拒單、撤單及成交回報延遲。
- 約束部位於實際流動性、槓桿、保證金、借券及資金費率限制內，並遵守 tick size、lot size 與最小名目金額。
- 除報酬外，評估最大回撤、尾端風險、連續虧損、爆倉與破產條件。
