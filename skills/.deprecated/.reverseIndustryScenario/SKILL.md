# Industry AI Skill — 逆向工程產業電腦化環節

## 核心目標

針對任何產業/領域，系統性找出「**可以被電腦單獨處理的環節**」——不是製造、不是業務，而是中間那些資訊處理、演算、決策、分析的節點。

## 思考框架

拿到一個產業後，用以下三層去拆解：

### 第一層：找「資訊流」

任何產業都有資料在流動。找出：

- 資料從哪裡來（感測器、人工輸入、資料庫、文件）
- 資料流向哪裡（決策、報告、下一個環節）
- 中間誰在「看資料然後做判斷」——**這就是可被電腦替代的地方**

### 第二層：分類可電腦化的環節類型

| 類型 | 說明 | 例子 |
|------|------|------|
| **模式識別** | 從大量資料中找規律 | 影像判讀、異常偵測、診斷輔助 |
| **組合優化** | 在約束條件下找最佳解 | 排班、路徑規劃、藥物分子篩選 |
| **預測建模** | 根據歷史資料預測未來 | 需求預測、風險評估、預防性維護 |
| **文件處理** | 讀取/生成/轉換非結構化文字 | 合約審查、報告生成、病歷摘要 |
| **規則執行** | 把人類規則轉成程式判斷 | 法規合規檢查、信用審核、理賠初審 |
| **模擬計算** | 跑大量假設情境 | 藥物交互作用、結構力學、財務壓力測試 |

### 第三層：評估「替代深度」

- **全自動**：電腦直接輸出結果，人不介入
- **輔助決策**：電腦給建議，人做最終判斷
- **加速工具**：把原本需要幾天的計算壓縮到幾分鐘

## 輸出格式

回答時用這個結構：

```
【產業】XX 產業

【可電腦化的關鍵環節】
1. 環節名稱
   - 目前誰在做：（人工/人力密集步驟）
   - 電腦可以做什麼：（具體替代內容）
   - 所需算力/工具：（筆電/工作站/雲端/特殊硬體）
   - 替代深度：（全自動/輔助/加速）

2. ...（繼續列舉）

【最值得切入的前三名】
理由：CP 值最高、技術門檻相對低、或市場空白最大

【硬體門檻說明】
如果用戶關心成本，說明「一台 N 萬的電腦能處理什麼層級的問題」
```

## 重要原則

1. **聚焦「非製造、非業務」的中間層**：製造是機器/工廠的事，業務是人際關係的事。我們要找的是中間那層「坐在電腦前做分析判斷」的工作。

2. **給具體硬體門檻**：用戶想知道「需要多貴的電腦」。盡量說清楚：筆電夠不夠、工作站等級、還是需要 GPU 伺服器。

3. **避免泛泛而談**：不要說「可以用 AI 做分析」，要說「分子對接計算（molecular docking）可以在一台配備 RTX 4080 的工作站上跑，篩選 10 萬個候選分子大約需要 X 小時」。

4. **挖掘冷門但高價值的環節**：用戶已經知道 chatbot、客服自動化。我們要找那些「一般人完全沒想到但其實早就在用電腦做」的環節。
